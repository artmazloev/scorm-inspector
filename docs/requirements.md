# Требования

Формат: стабильный ID + проверяемый критерий приёмки. Изменение требования — новая версия с `supersedes`, не тихая правка. Статусы: draft → accepted → implemented.

Источник: аналитическая сессия с владельцем 2026-09-06 (утверждено им же).

## Функциональные

| ID | Требование | Критерий приёмки | Статус |
|---|---|---|---|
| RQ-010 | Загрузка SCORM-пакета (zip) → автоматические структурные проверки → отчёт | загрузка валидного пакета даёт отчёт с ≥5 категориями проверок, у каждой находки severity | accepted |
| RQ-011 | Отчёт: машиночитаемый (JSON) + человекочитаемый в UI + скачивание | `GET /api/report/:id` валидный JSON; кнопка «скачать» в UI работает | accepted |
| RQ-012 | Плеер SCORM 2004 (3rd/4th ed.): iframe + эмуляция RTE, ошибки runtime ловятся на лету | синтетический тестовый пакет проигрывается; все Initialize/GetValue/SetValue/Commit вызовы логируются; невалидный вызов даёт находку | accepted |
| RQ-013 | Поэкранные комментарии: привязка к экрану, список всех комментариев | комментарий привязан к экрану курса и переживает перезагрузку страницы; есть сводный список по пакету | accepted |
| RQ-014 | Экспорт отчёта (находки + комментарии) в xlsx и pdf | скачанный файл открывается и содержит находки проверок и комментарии | accepted |
| RQ-015 | Аккаунты; пакеты и комментарии сохраняются между сессиями | логин работает; после перезапуска сервера пакеты и комментарии на месте | accepted |
| RQ-016 | Deployment: локальный запуск → Docker Compose на VPS | `docker compose up` поднимает приложение + Postgres одной командой | accepted |
| RQ-001 | (superseded by RQ-010) | — | superseded |
| RQ-002 | (superseded by RQ-011) | — | superseded |
| RQ-003 | (superseded by RQ-012 — определение версии SCORM входит в проверки RQ-010) | — | superseded |
| RQ-004 | (superseded by RQ-010 — целостность входит в проверки RQ-010) | — | superseded |

## Ограничения (must_not_break)

| ID | Ограничение | Критерий проверки |
|---|---|---|
| C-01 | SCORM 1.2 на старте не поддерживается — не ломать архитектуру его добавлением позже | движок проверок и плеер версионированы, версия — параметр, не константа |
| C-02 | Реальные учебные пакеты в репозиторий не заливаются | только синтетические фикстуры; CI проверяет отсутствие пакетов >N МБ |
| C-03 | Пакеты — чужой IP: наружу (публичный репо, отчёты) не попадают исходники пакетов | в отчёты/экспорт входят только находки и комментарии, не содержимое курса |
| C-04 | Стек TypeScript (Next.js + Postgres); отступления — через ADR | любой не-TypeScript код требует ADR |
