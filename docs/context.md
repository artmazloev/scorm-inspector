# Замысел

**scorm-inspector** — сервис по тестированию, отладке, воспроизведению и рецензированию SCORM-курсов.

Изначальная мотивация: корпоративная академия работает с SCORM-пакетами; приёмка и диагностика курсов сейчас ручная и неглубокая. Нужен инструмент, который:

1. Проверяет пакет до загрузки в LMS (manifest, файлы, runtime-вызовы).
2. Помогает находить причины «курс не финиширует / не ставится оценка».
3. Даёт минимальный воспроизводимый кейс для бага.
4. Формирует отчёт для рецензента.

## Ограничения по брифингу владельца

- Новый код — **Go** (брифинг: hard rule §1.2).
- Free/self-hosted first; публичный репозиторий, но **не заливать реальные учебные курсы** (личные/корпоративные данные) — только синтетические фикстуры.
- Разработка через фича-ветки + PR (main защищён).

Ещё не выбрана. Кандидаты: CLI-инструмент на Go (стандартная библиотека + archive/zip + encoding/xml), позже — веб-слой поверх CLI.
