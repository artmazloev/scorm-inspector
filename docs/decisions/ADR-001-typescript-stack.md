# ADR-001: Стек TypeScript end-to-end (Next.js + PostgreSQL)

## Статус

accepted (2026-09-06, утверждено владельцем)

## Контекст

Проект — веб-приложение с SCORM-плеером. Правило брифинга «новый код — Go» для этого проекта владельцем отменено: «выбрать идеальный стек под задачи». Плеер по сути — JS/TS в iframe, эмулирующий SCORM 2004 RTE; TypeScript даёт один язык на фронт, бэк и плеер.

## Решение

TypeScript end-to-end: Next.js (UI + API routes) + PostgreSQL (docker-compose, локально бесплатно). Плеер — TS в iframe.

## Последствия

- Один язык, одна тулчейн-цепочка, быстрый старт.
- SCORM 1.2 позже добавляется параметром версии (C-01).
- Отступления от стека — только через отдельный ADR (C-04).

## must_not_break

- Не завязывать бизнес-логику проверок на API routes так, чтобы движок нельзя было вынести в отдельный сервис.
- Не хранить содержимое пакетов в git (C-02, C-03).
