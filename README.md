# scorm-inspector

Инструмент для **тестирования, отладки, воспроизведения и рецензирования SCORM-курсов**.

## Назначение

- **Тестирование** — автоматические проверки пакета: структура, manifest, соответствие SCORM CAM.
- **Отладка** — поиск и объяснение проблем: битые ссылки, ошибки manifest, проблемы javascript API.
- **Воспроизведение** — детерминированное воспроизведение багов: зафиксировать входные условия (версия SCORM, runtime-данные) и получить минимальный воспроизводимый кейс.
- **Рецензирование** — структурированный отчёт для рецензента: что сломано, насколько критично, где чинить.

## Статус

🚧 Проект на стадии замысла. Требования и активный план ведутся в [docs/](docs/) и в канонической заметке в базе знаний (vault).

## Рабочий процесс

- Разработка — через фича-ветки + pull request (main защищён, требуется 1 approve).
- Требования — стабильные ID `RQ-xxx` с проверяемым критерием приёмки.
- Решения — ADR в [docs/decisions/](docs/decisions/).
